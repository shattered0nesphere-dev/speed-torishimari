# 速度取締り情報 PWA v0.1

iPhone Safariの「ホーム画面に追加」でアプリのように使えるWebアプリです。

- 47都道府県選択
- 市区町村入力
- 最大20地域を端末に保存
- 起動時に data/speed.json を更新
- 通信失敗時はキャッシュ表示
- 警察公式情報へのリンク
- X検索
- Google Maps

## 公開
GitHubにこのフォルダの中身を置き、Settings > Pages > Deploy from branch > main/root を選択してください。

## 注意
警察各サイトをブラウザから直接スクレイピングする方式はCORS等の制約があります。本版は更新用JSON方式です。現在は兵庫県の公式速度管理指針をサンプル登録しています。次段階で47都道府県の公式情報を調査して追加します。
